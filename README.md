# PodcastMeld

A simple PodcastMeld System for Auto Encoding.

With PodcastMeld, you get a lightweight tool that stays out of your way.

**What you get**

- A simple PodcastMeld System for Auto Encoding

## Key Features

- A simple PodcastMeld System for Auto Encoding

## Technology Stack

- rust
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/PodcastMeld.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

PodcastMeld is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
